## 🛠️ Project 1: Smart Mart Management & Analytics System

* **Standalone Repository:** [https://github.com/ShubhamAgre28/smart-mart-management-system](https://github.com/ShubhamAgre28/smart-mart-management-system)
* **Live Deployment:** [https://smart-mart-management-system.onrender.com](https://smart-mart-management-system.onrender.com)
* **Overview:** A high-throughput retail operations and Point-of-Sale (POS) platform featuring atomic transaction stock locking, low-stock alerts, supplier/customer CRM, and multi-month ADBMS comparative financial analytics.
* **Architecture:** 3-tier client-server architecture with dual database connectivity (MySQL 8.x pool with automated zero-config SQLite3 fallback).
* **Documentation Included:** Complete architectural [`README.md`](https://github.com/ShubhamAgre28/smart-mart-management-system/blob/main/README.md) and formal [`PROJECT_REPORT.md`](https://github.com/ShubhamAgre28/smart-mart-management-system/blob/main/PROJECT_REPORT.md).

## ⚡ Project 2: PLC-Based Forward–Reverse Motor Control System

* **Standalone Repository:** [https://github.com/ShubhamAgre28/PLC-Forward-Reverse-Motor-Control](https://github.com/ShubhamAgre28/PLC-Forward-Reverse-Motor-Control)
* **Target Controller:** Mitsubishi Electric MELSEC iQ-F (FX5U CPU)
* **Engineering Software:** MELSOFT GX Works3 & GX Simulator3
* **Overview:** An industrial automation project demonstrating bidirectional AC motor control using ladder diagram (LD) logic, digital inputs/outputs, self-holding (seal-in) contacts, and mutual electrical interlocking with Normally Closed (NC) stop pushbuttons.
* **Documentation Included:** Comprehensive [`README.md`](https://github.com/ShubhamAgre28/PLC-Forward-Reverse-Motor-Control/blob/main/README.md), Mitsubishi instruction listing, and ladder diagram assets.

## 📥 Cloning Both Projects

To clone this entire Semester 5 portfolio along with both independent project repositories on any computer, run:

```bash
git clone --recurse-submodules https://github.com/ShubhamAgre28/SEM-5-CAPSTONE.git
```

If already cloned without submodules:
```bash
git submodule update --init --recursive
```
